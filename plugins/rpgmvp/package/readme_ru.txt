RPGMVP для PictureView 3
************************

Показывает зашифрованные картинки игр на RPG Maker MV и MZ (.rpgmvp и
.png_) прямо в папке игры: спрайты, тайлсеты, лица, фоны. Без ключа,
без расшифровки, без распаковки. Декодер для PictureView — плагина
просмотра картинок для Far Manager 3.

Как пользоваться:
  Откройте файл так же, как любую картинку в PictureView. Файлы внутри
  архивов тоже работают. Прозрачность показывается; 16-битные PNG
  отдаются PictureView как 16-битные.

  У анимированных PNG (APNG) показывается только первый кадр. RPG Maker
  их всё равно не делает.

Установка:
  Распакуйте архив в папку PictureView (ту, где лежит 0PictureView.dll,
  обычно Plugins\PictureView вашего Far) и перезапустите Far. Для
  64-битного Far берите архив x64, для 32-битного — x86.

  Плагин самодостаточен: ему не нужны ни рантайм, ни кодеки, ни GDI+ —
  только сама Windows.
