SVG для PictureView 3
*********************

Показывает изображения SVG и SVGZ в PictureView — плагине просмотра
изображений для Far Manager 3. Рендерер resvg встроен в плагин.

Использование:
  Откройте файл SVG или SVGZ так же, как любое другое изображение.
  Показывается одна неподвижная страница в собственном размере.
  Текст рисуется шрифтами, установленными в Windows. Прозрачность,
  фильтры, обрезка, маски, градиенты и встроенные картинки обрабатываются
  так, как умеет resvg. Поддерживаются относительные ссылки на картинки
  для SVG, открытых с диска. Файлы SVG из архивов тоже открываются, но
  относительные ссылки могут не найтись: у записи в архиве нет надёжной
  папки документа. В интернет плагин не обращается.

  Ограничения: одна неподвижная страница; анимация, скрипты и
  интерактивные элементы не поддерживаются. При изменении масштаба
  PictureView увеличивает уже готовую картинку, заново SVG не рисуется.
  Изображения больше 16 384 пикселей по стороне или больше 67 108 864
  пикселей всего не открываются. Это не полная реализация SVG, как в
  браузере.

  При нехватке памяти внутри resvg возможно аварийное завершение Far.
  Проверки размеров не устраняют этот риск.

  Плагин не требует ни среды выполнения, ни дополнительных кодеков, ни
  GDI+. Библиотеки совместимости со старыми версиями Windows включены,
  но на Windows 7 плагин не проверялся.

Установка:
  Распакуйте архив в папку PictureView (ту, в которой находится
  0PictureView.dll; обычно это Plugins\PictureView в папке Far) и
  перезапустите Far. Для 64-битного Far используйте архив x64, для
  32-битного — x86.
